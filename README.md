# حمایت ۱۳ — Hemayat 13

نمونهٔ رابط کاربری فارسی و راست‌چین برای تجربهٔ همراهی/حمایت؛ ساخته‌شده با React، React Router و Vite.

## پیش‌نیاز

- Node.js نسخهٔ ۲۰.۱۹ یا جدیدتر
- npm

## اجرا در ویندوز PowerShell

در پوشه‌ای که فایل `package.json` مستقیماً در آن قرار دارد، اجرا کنید:

```powershell
npm.cmd install
npm.cmd run lint
npm.cmd run build
npm.cmd run dev
```

Vite نشانی محلی را در ترمینال نمایش می‌دهد (معمولاً `http://localhost:5173`). برای آزمودن گوشی روی همان Wi-Fi:

```powershell
npm.cmd run dev -- --host 0.0.0.0
```

سپس نشانی `Network` نمایش‌داده‌شده توسط Vite را در مرورگر گوشی باز کنید. ممکن است تنظیم فایروال ویندوز نیز لازم باشد.

## تغییر برند

- `public/brand-13.svg`: نشان عدد ۱۳ زرد روی زمینه مشکی
- `public/favicon.svg`: آیکون تب مرورگر
- `index.html`: عنوان صفحه و توضیحات موتور جست‌وجو
- `src/index.css`: رنگ‌ها و طراحی ریسپانسیو
- `src/pages/home.jsx`: محتوا، سوالات متداول و بخش‌های صفحه اول

## محدودیت‌های حیاتی این نسخه

- پرداخت واقعی متصل نیست. فرم حمایت صرفاً مبلغ را در رابط کاربری نمایش می‌دهد؛ هیچ پولی منتقل نمی‌شود.
- ورود و ثبت‌نام نمایشی‌اند و وضعیت را در `localStorage` نگه می‌دارند. این روش احراز هویت امن یا قابل استفاده برای حساب واقعی نیست.
- داشبورد و آمار کمپین داده‌های نمونه‌اند و از دیتابیس خوانده نمی‌شوند.
- دکمه اشتراک‌گذاری پیوند صفحه را با قابلیت بومی مرورگر یا Clipboard به اشتراک می‌گذارد؛ پیش از میزبانی، پیوند فقط محلی است.

## پیش از انتشار عمومی

برای استفادهٔ واقعی لازم است بک‌اند، احراز هویت امن و مدیریت نشست، دیتابیس، اتصال درگاه پرداخت از سمت سرور، رسیدگی به خطاها، سیاست حریم خصوصی، شرایط استفاده و آزمون امنیتی فراهم شود. هیچ رمز یا کلید محرمانه‌ای نباید در کد فرانت‌اند قرار گیرد.
